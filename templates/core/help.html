{% trans "Manage staff members, departments, tasks, and payroll." %}

{% trans "Adding a Staff Member" %}

  • {% blocktrans %}Click + Add Entry on the Payroll page.{% endblocktrans %}
  • {% blocktrans %}Select the Staff Member, set Period Start & End dates.{% endblocktrans %}
  • {% blocktrans %}Enter Gross Salary, Deductions (tax, insurance), and Bonuses.{% endblocktrans %}
  • {% blocktrans %}Net Salary = Gross + Bonuses − Deductions (auto-calculated on save).{% endblocktrans %}

  • {% blocktrans %}Go to Medical → + Log Injury, or click 🏥 Injury from a player's detail page.{% endblocktrans %}

{% trans "Email Alerts" %}

{% blocktrans %}When a new injury is saved, an email alert is automatically sent to managers. Ensure the Q cluster worker is running for async delivery.{% endblocktrans %}
